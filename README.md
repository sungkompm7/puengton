# กสิกรรมไร้สารพิษ & สุขภาวะพึ่งตน (PWA)

ติดตั้งบนมือถือได้ ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่อง

## ไฟล์ในโฟลเดอร์
- index.html  หน้าหลัก (พรีวิว + ปุ่มติดตั้งแอป)
- farm.html   บัญชีฟาร์ม
- health.html บัญชีสุขภาพ (ยา 9 เม็ด)
- manifest.webmanifest, sw.js, pwa.js, icons/  ส่วนที่ทำให้เป็น PWA

## วิธีใช้งาน (สำคัญ)
PWA ต้องเปิดผ่าน **https** หรือ **localhost** เท่านั้น ดับเบิลคลิกไฟล์ตรงๆ (file://) จะติดตั้งไม่ได้

1. อัปโหลดทั้งโฟลเดอร์ขึ้นเว็บโฮสต์ฟรี เช่น GitHub Pages, Netlify, Cloudflare Pages
   (หรือทดสอบในเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000)
2. เปิดครั้งแรก **ตอนมีอินเทอร์เน็ต** เพื่อให้ระบบเก็บไลบรารีและฟอนต์ไว้ในเครื่อง
3. กด "ติดตั้งแอป" (Android/Chrome) หรือ Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม (iPhone)
4. หลังจากนั้นปิดเน็ตแล้วเปิดแอปได้ตามปกติ

## อัปเดตแอป
แก้ไฟล์แล้วเปลี่ยน `VERSION` ใน sw.js (เช่น v1 -> v2) ผู้ใช้จะเห็นปุ่ม "มีเวอร์ชันใหม่"

## ข้อควรรู้
- ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนั้น ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ข้อมูลจะหาย → กด "สำรอง JSON" เป็นระยะ
- รูปภาพจำนวนมากอาจทำให้พื้นที่เก็บข้อมูล (~5MB) เต็ม ระบบจะแจ้งเตือน
